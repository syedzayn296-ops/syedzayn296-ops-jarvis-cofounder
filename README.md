# JARVIS Cofounder

JARVIS is an AI operating partner being developed for Zayzana Tech.

## Current capabilities

- Company and business context
- Strategic goals
- Decision recording and lifecycle
- Decision evidence
- Decision challenges
- Recommendation synthesis
- Lessons learned
- Founder approval gates
- Internal execution tracking
- One-shot execution protection

## Current architecture

Observe → Assess → Challenge → Recommend → Decide → Approve → Execute → Outcome → Learn

## Development status

The current build is a local Node.js prototype being prepared and tested on the Dell development machine.

Live OpenAI API work is intentionally parked until billing/credits are available.

## Safety

External actions are not executed automatically. Founder approval remains required before execution.
